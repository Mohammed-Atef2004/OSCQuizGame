# 🧠 Quiz Application (ASP.NET Core MVC)

A full-featured quiz web application built using ASP.NET Core MVC and Entity Framework Core.

## 🚀 Features

- Dynamic quiz generation per category
- Session-based user tracking
- Randomized questions per attempt
- Real-time scoring system
- Winner leaderboard for high scores
- Clean MVC architecture

## 🏗️ Tech Stack

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views
- Bootstrap 5

## ⚙️ How it works

1. User selects a category
2. Registers with name & email
3. Receives 10 randomized questions
4. Answers are evaluated in real-time
5. Score is calculated automatically
6. High scorers are saved to leaderboard

## 📊 Architecture

- Controllers handle quiz flow logic
- Session stores user progress
- EF Core manages data persistence
- Razor Views render UI

## 🧠 Key Concepts Used

- Session Management
- LINQ Queries
- EF Core ORM
- MVC Pattern
- State Tracking
